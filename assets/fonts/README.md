# Social card fonts

The social-card renderer bundles the same two Google Fonts families used by the website so generated images do not depend on locally installed fonts.

- `Unbounded-Variable.ttf`: [Google Fonts source](https://github.com/google/fonts/blob/main/ofl/unbounded/Unbounded%5Bwght%5D.ttf), SHA-256 `323b511be380c8d474ef030686b71aedde501f8d9cd46da558b7c40454372c3f`
- `PlusJakartaSans-Variable.ttf`: [Google Fonts source](https://github.com/google/fonts/blob/main/ofl/plusjakartasans/PlusJakartaSans%5Bwght%5D.ttf), SHA-256 `89b3fb38aa0d275d7a731d0d817a4f1622b316b4d7fbdedcf02ee9099ff68bc8`

Both families are distributed under the SIL Open Font License 1.1. The corresponding licence files are stored beside the fonts.
