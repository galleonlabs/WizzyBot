# Una

The one-click market maker for memes.

Deposit ETH once. Una opens the same reviewed meme-market index across Base, Robinhood Chain, and Solana. You own every Uniswap or Aerodrome NFT and every Meteora position.

- One amount. No pool, range, bridge, or allocation builder.
- Privy creates the EVM and Solana wallets under one login.
- Relay funds the destination networks; Una prepares the positions.
- Pool fees, position value, range health, reinvestment, and withdrawals stay visible in one portfolio.
- Market policy lives in version-controlled allowlists. Wallet and chain state remain authoritative.
